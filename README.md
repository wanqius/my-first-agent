# 我的智能体练习集

> 两个从零手写的智能体练习项目，全程不依赖任何 Agent 框架——**循环、工具分发、协议解析、错误兜底，全部自己写**。
>
> 这不是生产项目，是一份**学习记录**：每个项目都附带了「踩过的坑」和「已知限制」。

---

## 目录

| 目录 | 项目 | 一句话 |
|---|---|---|
| **`agent/`** | 多步 Agent | 自己判断要不要调工具、多轮执行、带六道保险与记忆 |
| **`memo/`** | 心情小助手 | 第一个手写程序：输入 → 存文件 → 调模型 → 回应 |
| **`examples/`** | 实验代码 | 死循环演示等小实验 |

## 快速开始

两个项目都只依赖 `requests` 和一个 DeepSeek API Key。

```bash
pip install requests

# 设置密钥（不要写进代码）
# PowerShell
$env:DEEPSEEK_API_KEY = "sk-你的key"
# Windows CMD
set DEEPSEEK_API_KEY=sk-你的key
```

```bash
cd agent && python agent.py      # 多步 Agent
cd memo  && python memo.py       # 心情小助手
```

## 学习路径

```
阶段 1  在低代码平台（扣子）做出一个可发布的智能体
         ↓  理解了 人设 / 知识库 / 工具 是什么
阶段 2  手写第一个程序 memo/：输入 → 存文件 → 调模型 → 回应
         ↓  理解了 API、文件读写、异常处理
阶段 3  手写 agent/：循环 + 工具分发 + JSON 协议 + 六道保险 + 记忆
         ↓  理解了 Agent 的骨架
阶段 4  框架与工程化（进行中）
```

**这条路径的关键不是"学过什么"，而是每个阶段都有能跑、能讲清的产物。**

## 这个仓库的原则

1. **不藏坑** —— 每个项目都有「踩过的坑」表格，写明现象、根因、修复
2. **不留假话** —— 每个项目都有「已知限制」，没做完的事直接写出来
3. **不堆代码** —— 只有 `agent/` 和 `memo/` 两个项目，其余都是它们的说明
